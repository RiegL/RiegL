<h2 align="center">🚀 Full-Stack Software Engineer | Java · Spring Boot · Next.js · Fintech</h2>

Full-stack software engineer with **4+ years of experience** building web and mobile applications. Today I work with **Java, Spring Boot, React, and Next.js**, along with **PostgreSQL, SQL, AWS, and Docker**. Previously, I worked with **Node.js, React/Next.js, and React Native**.

I enjoy solving real problems end-to-end — from understanding business requirements and designing APIs and data models to building interfaces and integrating different services.

## 💻 Professional Experience

### 🏦 Nortis Tech — Co-founder & Full-Stack Engineer *(Dec 2025 – Present)*

I co-founded **Nortis Tech**, where I helped finalize and continue to evolve a **multi-tenant BRL/USDT OTC exchange platform** for a fintech client. I develop its business modules and integrations across the system — payments, wallets, transactions, financial records, and invoicing.

The platform is a **modular monolith** built with **Java, Spring Boot, Spring Modulith, PostgreSQL, AWS, Docker, and React/Next.js**, with modules organized by business domain, domain events to decouple them, and USDT operations integrated with the **TRON blockchain**.

Working on a financial platform has given me experience dealing with systems where **data consistency, security, reliability, and correctness are critical**, as well as complex business rules and integrations. Highlights:

* 🧪 Codebase with unit and integration tests using **JUnit 5, Testcontainers (real PostgreSQL), and REST-Assured**, with architecture rules automatically enforced by **ArchUnit**
* 🔐 Contributed to **LGPD compliance** features, including audit trails for personal data access
* 🤖 Adopted **AI-assisted code review** in my workflow, catching issues earlier and speeding up releases to production

## 🚀 Projects

### 📅 Vale Lorena Eventos — Booking & Rental Management System

A **booking and rental management system developed for a real events venue**, replacing a manual, paper-based scheduling process.

The system centralizes the venue's rental operations. Customers can request an event date through the public landing page, while the requests are managed internally through the administration system.

The system is actively used in production and includes:

* 📅 Public event date request flow
* 🔒 Automatic date availability and conflict detection
* 📊 Internal administration panel
* 💰 Rental and pricing management
* 🤝 Negotiation management
* 📋 Centralized booking and event management

🔗 https://www.valelorenaeventos.com.br/

### 🐝 Rieg Bee Meliponário — Stingless Bee Management System

A **web-based management system for stingless bee colonies**, developed to replace a previously manual process based on paper records or no centralized records.

The system allows each bee box to be individually registered and tracked, including:

* 🐝 Bee species
* 🔗 Origin and relationship to another box
* 💪 Colony strength — strong, medium, or weak
* 🔧 Maintenance information
* 🔔 Management alerts

The system includes authentication with different user roles. Administrators can manage user access, while regular users can access the management features according to their permissions.

Built with **React and Firebase**, the system is currently used in production and allows the user to keep centralized information about each box and colony.

🔗 https://app.riegbeemeliponario.com.br/login
